Как это устроено в БД
-- Дерево регионов: страна → область → город (adjacency-list + защита от циклов)
WITH RECURSIVE region_tree AS (
    SELECT id, parent_id, name, kind, 1 AS level
    FROM public.region WHERE code = 'BY'            -- корень: страна
  UNION ALL
    SELECT r.id, r.parent_id, r.name, r.kind, t.level + 1
    FROM public.region r JOIN region_tree t ON r.parent_id = t.id
) CYCLE id SET is_cycle USING path
SELECT name, kind, level FROM region_tree WHERE NOT is_cycle ORDER BY level, name;

-- ltree-путь для быстрых выборок (клиенты по области/городу) и AI:
-- SELECT * FROM region WHERE ltree_path <@ 'by.minsk_obl';

Город привязывается к контрагенту (адрес) и к маршрутам доставки. kind = страна/область/город. Счётчик клиентов — агрегат по поддереву (область включает свои города).
