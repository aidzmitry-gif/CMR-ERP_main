# Честный мокап — правила и шаблон

Мокап опасен, когда прячет разрыв «прототип ↔ реальность»: фейковые кнопки скрывают, что вся
боль в проводке (реальные данные, состояния, права, edge-cases). Честный мокап делает этот
разрыв ВИДИМЫМ — тогда Gate 1/2 решают по правде, а не по красоте.

## Правила
1. **Помечай real-vs-demo.** Каждое число/таблица/поле: реальное (из 1С/MDM/БД) или demo-заглушка?
   Бейдж провенанса (в проекте — `<SourceTag>` MDM/1С; honest-empty для пустого) прямо в мокапе.
2. **Фиделити под РЕШЕНИЕ, не пиксель-перфект.** Цель — одобрить флоу/связи/взаимодействие, не прод-полиш.
   Перелак = платишь дважды (мокап + порт). Достаточно, чтобы оператор понял и сказал «хорошо».
3. **Показывай все состояния** — пусто / загрузка / ошибка / нет прав / успех. Не только happy-path
   (именно скрытые состояния — основная стоимость реализации).
4. **Не полируй заблокированное.** Если способность за блокером (методика цены, запись в 1С заморожена) —
   мокап помечает блок явно («demo: цена-заглушка, методика не готова»), а не притворяется рабочим.
5. **Связи реальные, данные — нет.** Все переходы/окна должны быть, чтобы вскрыть бэкенд-контракт (Gate 2),
   но данные могут быть demo.

## Маркеры (соглашение)
- `data-demo="true"` на элементах с фейковыми данными → CSS-бейдж «demo» в углу.
- `data-source="1C|MDM|module|none"` → провенанс (как `<SourceTag>` в живом фронте).
- Видимый штамп вверху прототипа: «🟡 ПРОТОТИП — данные demo, кроме помеченных 1С/MDM».

## Мини-сниппет (паттерн, не копипаста)
```html
<div class="proto-banner">🟡 ПРОТОТИП · данные demo, кроме помеченных источником</div>
<!-- реальное поле из MDM -->
<span data-source="MDM">ООО «Ромашка» <em class="src">MDM</em></span>
<!-- demo-число: маржа (методика цены — блокер, см. Gate 2) -->
<span data-demo="true">22% <em class="badge">demo</em></span>
<!-- пустое честно -->
<div class="empty">Нет данных — подключим из 1С на реализации</div>
```

## Чек перед Gate 1
- [ ] Все окна + переходы есть и кликабельны.
- [ ] Каждое число помечено real/demo; блокеры названы явно.
- [ ] Состояния пусто/загрузка/ошибка показаны.
- [ ] Не перелакировано (decision-fidelity).
