# Задача: редизайн досок Sales 2.0 на 2 темы

Переведи 3 HTML-макета на дизайн-систему с двумя темами (светлая C / тёмная D) строго по
контракту **`coordination/mockup-redesign-tokens.md`** и эталону **`sales-card-full.html`**
(он уже готов — копируй его решения 1:1).

Твои файлы (только эти, не трогай чужие):
- `sales-board-mockup.html` — доска сделок (sticky-скорборд, воронки, канбан, рейка чатов, drawer).
- `sales-board-before-after.html` — доска До/После (две колонки сравнения).
- `sales-board-chat-preview.html` — прототип доски с рейкой чатов (свой layout, имена переменных `--brand50` без дефиса, `--card`/`--line`).

Цель (Goal-Driven): после правок каждый экран открывается в `http://127.0.0.1:8899/<файл>.html`,
переключатель темы 🌙/☀️ работает, в ТЁМНОЙ теме нет «белых пятен» (светлых фонов), синий-brand
заменён на accent-токен, шрифт Inter, все блоки на месте, JS не сломан.

ВАЖНО для досок:
- Цветные полосы стадий канбана (`--s-new/--s-qual/...` или `.strip`) — это СТАТУС-цвета воронки,
  НЕ трогать (они и должны быть цветными).
- Тёмные оверлеи модалок/drawer (`rgba(15,23,42,.4)` и т.п.) — оставить как есть (это затемнение фона).
- НЕ делать рекурсивных объявлений `--brand:var(--brand)` — в объявлении переменной ставь реальный hex,
  а двухтемность даёт аппенд-слой (см. контракт, шаг 2) либо правь :root напрямую как в эталоне.
