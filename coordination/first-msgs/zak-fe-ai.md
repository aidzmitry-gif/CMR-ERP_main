# zak-fe-ai — задание воркеру

Ты верстаешь **2 статичных HTML-экрана** прототипа модуля «Закупки» (ZAK): **«AI-переписка с поставщиками»**
и **«Мониторинг цен + проверка контрагентов»**. Это превью-снимки будущих Next.js-экранов (как
`rop-*-preview.html`), НЕ React, НЕ backend. Демо-данные, BYN; китайские цены — CNY (¥). Центр обоих
экранов — **ИИ-агенты**: переписка, перевод, переговоры, мониторинг, проверка контрагентов, документы.

## ЭТАЛОН — копируй один-в-один
Открой **`zak-cockpit-preview.html`** в корне репо. СКОПИРУЙ без изменений:
1. весь `<head>` (Tailwind CDN + токены canvas/ink/muted/brand + `<style>` с `body{...}` и блоком `.chatrail/.av/.badge/...`);
2. весь `<aside class="chatrail">…</aside>` (панель чатов справа) — дословно;

Контейнер — `<div class="mx-auto max-w-[1180px] space-y-4 p-6 pr-[92px]">` (`pr-[92px]` обязателен).
Карточки/бейджи/ИИ-блок — классами как в cockpit.

## Экран 1 — `zak-ai-comms-preview.html` (вкладка «AI-переписка» активна)
**ИИ автоматизирует переписку с поставщиками** (в основном WeChat, плюс email, 1688): переводит,
отвечает по шаблону, ведёт переговоры по цене, делает аналитику бесед, готовит документы для закупки/импорта.

Свёрстай:
- Заголовок «AI-переписка с поставщиками» + подзаголовок (WeChat / email / 1688: перевод, ответы, переговоры, аналитика).
- Полоса метрик ИИ (4 мини-карточки): диалогов активно, ответов за день, черновиков на ревью, договорённостей зафиксировано.
- **Главный макет** (`grid lg:grid-cols-[300px_1fr] gap-4`):
  - **Слева — список диалогов**: поставщик (кит. имя + лат.), канал-бейдж (WeChat/email/1688), последнее
    сообщение, время, бейдж непрочитанных. 5–6 диалогов, один выбран (`ring-2 ring-brand/40`).
  - **Справа — тред выбранного диалога** (карточка): шапка (поставщик + канал + кнопка-плашка «企信宝: надёжный»).
    Лента сообщений пузырями:
    - входящие от поставщика — китайский текст в пузыре (`bg-slate-100`), ПОД ним мелким курсивом
      `text-[12px] text-slate-400` — **перевод ИИ** на русский;
    - исходящие — справа (`bg-brand text-white`);
    - **черновик ответа ИИ** — выделенный блок `border border-dashed border-violet-300 bg-violet-50`
      с текстом предлагаемого ответа (рус + кит.) и неактивными кнопками «Отправить» / «Поправить».
    Сделай 4–6 реплик диалога про согласование цены/срока.
- **Блок «Аналитика беседы» (ИИ извлёк)**: чипы/строки — согласованная цена ¥3.85/шт, срок 25 дней,
  MOQ 5000, условие предоплаты 30%, **риск**: поставщик упомянул рост цен на сырьё (amber). + «тон беседы: конструктивный».
- **Блок «Документы»**: ИИ сформировал — инвойс (PI), упаковочный лист, контракт; бейджи «готово»/«на проверке».

## Экран 2 — `zak-price-monitor-preview.html` (вкладка «Мониторинг цен» активна)
**Контроль цен** на постоянно закупаемые товары на **1688 / Taobao / Alibaba** + **проверка контрагентов** в Китае.

Свёрстай:
- Заголовок «Мониторинг цен и контрагентов» + подзаголовок.
- Полоса метрик (4 мини-карточки): товаров на контроле, алертов за неделю, экономия BYN/мес, новых контрагентов на проверке.
- **Блок «Алерты цен»** (наверху, заметный): 2–3 алерта — «STM32F103 на 1688 +12% за неделю → есть аналог
  у Hangxin −8%» (amber/red), с мини-стрелкой ↑/↓ и неактивной кнопкой «Переключить поставщика».
- **Таблица watchlist**: товар, площадка (бейдж 1688/Taobao/Alibaba), текущая цена ¥, изменение (↑↓% цветом),
  порог алерта, поставщик, аналоги (число). 6–8 строк. Для пары строк — мини-спарклайн ценой из тонких
  div-баров (`flex items-end gap-0.5 h-8`, разной высоты).
- **Блок «Проверка контрагентов в Китае»** (реестр): как в cockpit, но развёрнуто — таблица: контрагент (кит.),
  площадка, рейтинг ИИ (Надёжный/Осторожно/Риск — emerald/amber/red), годы на рынке, капитал, суды, жалобы,
  источник (企信宝/天眼查). 4–5 строк.
- **ИИ-блок** (ghost): ИИ ежедневно сканирует площадки по watchlist, ловит рост, ищет аналоги дешевле,
  проверяет новых поставщиков до предоплаты (企信宝/天眼查 + история сделок + отзывы). 2–3 пункта.
