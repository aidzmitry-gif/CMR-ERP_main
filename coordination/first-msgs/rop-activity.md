# Задание воркеру `rop-activity`

Ты строишь demo-экран РОП **«Активность · ведущие индикаторы»** для CRM (Next.js App Router,
Tailwind). Это витрина концепта на demo-данных — как соседние экраны РОП. Цель (goal-driven):
**создать страницу + файл данных так, чтобы `npx tsc --noEmit` был зелёным и маршрут
`/crm/rop/activity` компилировался, а вид совпадал по стилю с эталоном `cash/page.tsx`.**

## СНАЧАЛА прочитай (контекст и стиль — не угадывай)
- `frontend/src/app/crm/rop/cash/page.tsx` — ЭТАЛОН структуры/стиля (копируй паттерн).
- `frontend/src/components/rop/ui.tsx` — примитивы: `Card, Caption, Tag, Bar, Dot, Avatar`,
  палитры `TEXT_TONE, BAR_TONE, TAG_TONE, BORDER_TONE`, тип `Tone`.
- `frontend/src/components/rop/rop-tabs.tsx` — `RopTabs`; ключ `"activity"` УЖЕ в union — НЕ менять.
- `frontend/src/lib/rop-data.ts` — только посмотреть форму данных и взять `import type { Tone }`.

## Окружение (важно!)
В worktree нет `frontend/node_modules`. Перед `tsc` подними junction на main-репо:
```
cd "<worktree>\frontend"
cmd /c mklink /J node_modules "d:\6 Проекты\CRM ERP\Сlaude CRM - проект\frontend\node_modules"
npx tsc --noEmit
```
Линтер в проекте НЕ установлен — `npm run lint` НЕ запускать; гейт качества — `tsc --noEmit`.

## Что построить (2 файла)

### `frontend/src/lib/rop-activity-data.ts`
Чистые типизированные demo-данные (валюта не нужна, это активность). `import type { Tone } from "@/lib/rop-data"`.
Закодируй РОВНО эти числа (они сведены с другими экранами — звонки и win% совпадают с Обзором):

**Дневная активность отдела (факт / норма):** звонки 18/40, КП 3/5, встречи 2/3, новые 1/2.

**Воронка ведущих индикаторов за месяц (отдел):**
Звонки 420 → Встречи 96 (конв. 23%) → КП 54 (конв. 56%) → Сделки 13 (конв. 24%).

**По менеджерам** (звонки / встречи / КП / сделки / конв. звонок→встреча / win% / тон / заметка):
- Анна А. — 58 / 22 / 16 / 6 — 38% / 28% — green — «качество выше объёма, эталон конверсии»
- Дмитрий Д. — 41 / 14 / 10 / 4 — 34% / 26% — amber — «норма по этапам»
- Мария М. — 33 / 9 / 6 / 3 — 27% / 22% — amber — «теряет на квалификации (звонок→встреча)»
- Сергей С. — 22 / 5 / 4 / 1 — 23% / 12% — red — «объём низкий и конверсия низкая — качество звонков»

**Инсайт:** «Ведущие индикаторы (звонки→встречи) предсказывают продажи за ~24 дня (цикл сделки).
Сергею — коучинг качества звонка, не количества; Анна — эталон конверсии звонок→встреча.»

### `frontend/src/app/crm/rop/activity/page.tsx`
Серверный компонент (без `"use client"`, без хуков/onClick). Структура как в `cash/page.tsx`:
- `AppShell crumbs={["CRM", "РОП", "Активность"]}`, `main className="flex-1 overflow-auto bg-canvas p-6"`,
  контейнер `mx-auto max-w-[1220px] space-y-4`, заголовок h1 `text-xl font-bold text-ink` + подзаголовок.
- `<RopTabs active="activity" />`.
- Блок 1 — «Сегодня · активность отдела»: 4 мини-метрики факт/норма (звонки/КП/встречи/новые) с `Bar`.
- Блок 2 — «Воронка ведущих индикаторов»: Звонки→Встречи→КП→Сделки с `Bar` (ширина = доля от звонков)
  и подписями конверсий; пометь, что звонок→встреча — ранний предиктор.
- Блок 3 — таблица по менеджерам (как таблица команды в cash): `Avatar` + имя + заметка, колонки
  звонки/встречи/КП/сделки, конв. звонок→встреча (с `Bar`+%) и win% (тон по менеджеру). Строка-инсайт снизу.
- Все цвета — через палитры `TEXT_TONE/BAR_TONE/TAG_TONE`, hex не хардкодить. Широкие таблицы — `overflow-x-auto` + `min-w`. `th` с `scope="col"`.
