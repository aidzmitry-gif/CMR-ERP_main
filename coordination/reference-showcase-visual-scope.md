# Задание: Справочники — внешний вид витрины на реальных данных

> Постановка: оператор через координатора, 2026-07-03. Полоса: **Справочники (reference-data)**.
> Общий приоритет оператора сейчас: «сначала внешний вид».

## Контекст

В dev.db реальные данные (backfill Bitrix24+1С): 431 контрагент (алиасы 364 bitrix + 160 1c),
**232 SKU** (209 с провенансом `source: 1c`, коды `КА-xxxxx`), **37 категорий** — реальное дерево
видов номенклатуры 1С. Бэк `127.0.0.1:8000` (IPv4, не менять), фронт :3000.
Находка ui-crawl координатора (2026-07-03): **в хабе `/erp/spravochniki` НЕТ плитки
«Номенклатура/SKU»** — карточка SKU достижима только прямым URL.

## Объём

1. **Плитка «Номенклатура» в хабе** `/erp/spravochniki` → каталог SKU: таблица (код, название,
   ед., категория, НДС, активность) + поиск + фильтр по категории. Реальные 232 позиции.
2. **Кликабельный путь до карточки**: хаб → каталог/дерево категорий → карточка
   `/erp/spravochniki/sku/[code]` (сейчас до неё не добраться кликами). Закрыть известный
   техдолг обхода дерева категорий (2-уровневое, 37 узлов).
3. **Сверка витрины на реальных данных**: карточка SKU (шапка/ТН ВЭД/пошлина/НДС/провенанс),
   контрагенты (голова+филиалы по УНП), категории. Кириллица/длинные названия 1С не рвут вёрстку
   («Аккумулятор литиевый SAMSUNG 3INR18650-25R 11,1V2500mah 20A страна происх. Корея»).
   Провенанс-пометки «из 1С» видны (канон mdm-провенанса).
4. Светлая + тёмная тема (класс `dark` на `<html>`), узкий вьюпорт. Honest-empty там, где данных
   нет (SCD2-версии пусты — это норма, не чинить).

## Ограничения (координатор)

- **Миграции НЕ заводить** — голова `0089`, номер только через координатора. Задание — UI/витрина,
  схему не трогает.
- `modules/integrations/**` — территория синк-полосы, не трогать. Запись в 1С запрещена (read-only).
- Хаб/фронт справочников — ваши файлы (`frontend/src/app/erp/spravochniki/**`,
  `frontend/src/lib/reference-data*`); хотспоты (`api.ts` и др.) — захват строкой координатору.
- Коммиты локально в `sales-2.0-redesign`, БЕЗ push (пакет ждёт отмашки оператора).
- Скриншоты — Playwright MCP (preview_* виснет на SSE).
- Эстетика — канон `frontend/DESIGN.md` (темы C/D), примитивы `src/components/ui`.
