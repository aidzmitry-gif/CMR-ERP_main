# DoD — единый контракт «готово» для полосы

> Лёгкий floor перед маркером `КООРД: DONE`. Route-зависимый, без тяжёлого авто-critic.
> Цель — убрать «у каждой полосы своё понятие готового» и скрытую latency переделок.
> Приоритеты при конфликте — PLATFORM.md (деньги → безопасность → функции → эстетика).

## Базовый floor (ВСЕГДА перед DONE)
- [ ] **Ревью пройдено:** полоса зовёт `/code-review` (баги/корректность) → `/simplify` (чистка
  по «лестнице лени») РУКАМИ — с 2.1.215 ассистент их сам не инициирует. `/code-review` уходит
  фоновым сабагентом: галку ставим ПОСЛЕ возврата findings уведомлением, не после запуска. Для
  глубокого ревью T1-зоны — `/code-review ultra` (только оператор).
- [ ] **Тесты зелёные по своему скоупу:** `python scripts/lane_check.py <полоса>` → GATE: PASS (или явно объяснён каждый FAIL). Импорт `import main` не падает.
- [ ] **Линт чист** по тронутым файлам (`ruff check .` зелёный; фронт — `tsc --noEmit`).
- [ ] **Коммит-гигиена:** staged ТОЛЬКО свои файлы (`git add` по именам, НЕ `add .`); НИКАКОГО amend/reset/rebase на общей ветке; на общей ветке — НОВЫЙ коммит, push своего cherry-pick'ом (или своя lane-ветка/worktree).

## Route-зависимые добавки (по триггеру)

| **миграция** | номер через `scripts/next_migration.py` (НЕ инкрементить markdown руками); `alembic heads == 1` (pre-commit гард подстрахует); пинг координатору вписать в счётчик |

## Само-сертификация (формат доклада)
Закрывая задачу, полоса пишет маркер с чек-боксами (Stop-хук соберёт в REPORTS.md):
```
КООРД: DONE <полоса> — <суть> [DoD: ✓review ✓tests ✓lint ✓commit (+✓migration/✓security/✓depmap/✓ui-crawl по триггеру)] [%: NN]
```
Если что-то НЕ сделано — честно `✗` + причина, или статус `BLOCKED`/`NEEDS-*` вместо `DONE`.

- **`[%: NN]`** — твоя оценка готовности модуля ПОСЛЕ этой работы (0–100, та же методика, что в `coordination/readiness.json`: бэк/фронт/данные/тесты, AI-mock по дизайну не штрафуем). Координатор переносит число в `readiness.json` (канон % → рендерится в STATUS.md). **Ставить при заметном сдвиге готовности**, не на каждую мелкую правку. Так % ведутся инкрементально — без пере-замера агентами.

> Это floor, не бюрократия: для 10-строчной правки большинство строк закрываются за секунды.
> Спот-чек 2-3 полос в неделю достаточно — доверие + выборочная проверка, не тотальный аудит.
