# Модели LM Studio под голосового ассистента — решение (deep-research 2026-06-17)

> 105 агентов, 25 фактов → 11 подтверждено. Под AMD Ryzen AI Max+ 395 (96-128GB, Vulkan/llama.cpp).

## ОСТАВИТЬ (ядро, ~23-29 ГБ)
- **qwen3.6-35b-a3b** (22 ГБ) — основной локальный мозг (обезличивание/классификация/сверх-секретное). Qwen3 — топ по русскому.
- **paddleocr-vl-1.5** (0.9 ГБ) — OCR русских фото; бьёт Qwen3-VL-235B на документах, поддерживает кириллицу.
- **text-embedding-bge-m3** (0.6 ГБ) — семантический поиск по RU-заметкам; лидер ruMTEB Retrieval, 8192 токена vs 512 у E5.
- **qwen3-vl-8b** (6 ГБ) — vision, ТОЛЬКО если PaddleOCR слаб на рукописном (иначе тоже удалить).

## УДАЛИТЬ (~116 ГБ)
- qwen3-coder-next 80B (48) — для кода, не для ассистента.
- qwen3-next-80b-a3b-instruct (48) — избыточен, 35B хватает.
- qwen3-30b-a3b-instruct-2507 (18) — дубль 35B.
- nomic-embed-text (0.08) — дубль bge-m3 (хуже для русского).
- whisper-large-v3-turbo (0.5) — НЕ запускается в LM Studio (нет аудио-движка).

## ДОКАЧАТЬ
- Маленькая 3B-8B (Qwen3-4B / Gemma3-4B, Q4_K_M) — для частого лёгкого обезличивания, не гонять 35B на мелочь.

## КРИТИЧНО
1. **Whisper в LM Studio невозможен** (движок только текстовый llama.cpp). Транскрипция — отдельным whisper.cpp/faster-whisper.
   Наш текущий CPU-путь (faster-whisper) — правильный. GPU-транскрипция = whisper.cpp+Vulkan отдельно.
2. **Обезличивание не идеально:** SOTA-модели ловят ~93% сущностей в русском NER (recall<1.0). Локальный LLM-маскинг —
   НЕ единственная защита. Оборона в глубину: regex для телефонов/сумм/УНП (100%) + сверх-секретное вообще не слать Claude
   + ручная проверка чувствительного.

## Квантизация (на 96GB)
Q4_K_M — баланс по умолчанию; Q6_K — sweet spot качество/скорость; Q8_0 — только макс. качество. FP16 не нужен.

## Не подтвердилось
Конкретные t/s для 30B на Strix Halo (refuted) — точную скорость не обещать. GigaEmbeddings/FRIDA лучше bge-m3 на ruMTEB,
но не проверено и не упаковано под LM Studio — bge-m3 остаётся безопасным выбором.
