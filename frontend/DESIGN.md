# DESIGN.md — дизайн-система фронтенда

Единые правила визуального языка CRM/ERP. **Источник истины для чисел — `frontend/tailwind.config.ts`**
(цвета, тени, радиусы) и `globals.css` (шрифт, скроллбар). Этот документ объясняет
*когда что применять*; конкретные значения берутся из конфига, а не дублируются по экранам.

> ## ✅ ПРИНЯТО (2026-06-17) — направление + токены
> Стиль продукта зафиксирован как **Stripe/Notion** (светлый, тёплый). Канон:
> - **Шрифт** — Inter (`next/font`, `var(--font-inter)`) + табличные цифры (`tabular-nums`) на всех числах.
> - **Акцент** — индиго `accent #635BFF` (не старый brand-синий). **Деньги** — `money #0F9D58` (приоритет №1).
> - **Тени** — мягкие многослойные `shadow-card`/`shadow-pop`. **Радиусы** — 10/12/14px.
> - **Примитивы приняты:** `Button` (8 вариантов), `Card`, `Badge` — в `src/components/ui/`. Витрина: `/design`.
> - Демо в новом стиле: `/design/rop`, `/design/board`, `/design/deal-card`.
> - Дизайн служит приоритетам платформы (см. [../PLATFORM.md](../PLATFORM.md)): деньги→безопасность→функция→эстетика.
>
> **Старый brand-синий — legacy.** Живые экраны мигрируют на токены `accent`/`money` по мере правок.
> Ещё НЕ собрано (добираем по ходу): Input/Select/Textarea, Table (TanStack), Modal/Drawer, графики.

**Эталон стиля** — кокпит РОП (`/crm/rop`). Новый экран должен выглядеть как часть того же
продукта: та же палитра, та же типографика, те же карточки/бейджи/таблицы/кнопки.

> Правило одной строкой: **цвет/размер не выдумывать — взять токен из `tailwind.config.ts`.
> Нет подходящего токена → сначала добавить токен, потом использовать. Захардкоженный hex
> в компоненте — это долг.**

## 1. Палитра

Все цвета определены в [tailwind.config.ts](tailwind.config.ts) → используй классы Tailwind
(`bg-brand`, `text-ink`, `text-muted`, `bg-stage-won` …), не hex.

| Токен | Hex | Назначение |
|---|---|---|
| `brand` (600) | `#2563EB` | Акцент, CTA, активная вкладка, ссылки |
| `brand-700` | `#1D4FD7` | Hover на brand-кнопках |
| `brand-50/100` | `#EFF5FF` / `#EAF1FF` | Светлая заливка под акцентом (бейдж, фон AI-чипа) |
| `canvas` | `#F4F5F7` | Фон страницы (`body`) |
| `ink` | `#1F2937` | Основной текст, заголовки |
| `muted` | `#6B7280` | Вторичный текст, подписи, мета |

**Семантика статусов** (используем шкалу Tailwind `emerald/amber/red/teal/violet/slate` —
эти оттенки уже сложились в макетах; держим их едиными):

| Смысл | Цвет | Где |
|---|---|---|
| Успех / факт / закрыто | `emerald-500` `#10B981` (`stage.won` `#22C55E`) | выполнено, в графике, оплата прошла |
| **Прогноз / обязательство** | `teal-500` `#14B8A6` (`stage.appr`) | **фишка РОП:** green = факт, teal = прогноз. Не путать |
| Предупреждение / отставание | `amber-500` `#F59E0B` (`stage.prop`) | требует внимания, риск срыва |
| Ошибка / отказ / критично | `red-500` `#EF4444` | проигрыш, просрочка, дефицит |
| AI / спецблок | `violet-500` `#8B5CF6` (`stage.qual`) | рекомендации ассистента, ИИ-инсайты |
| Нейтраль / неактивно | `slate-100` фон + `slate-500` текст | низкий приоритет, черновик, «пусто» |

**Стадии воронки** — отдельная шкала в `colors.stage` (`new/qual/prop/appr/won`). Это полоса
сверху канбан-колонки и точки стадий — брать **только** оттуда, не подбирать вручную.

> ⚠️ **Долг (не плодить):** цвета приоритетов сейчас скопированы в трёх местах
> (`priority-badge.tsx`, `deal-actions.tsx`, `funnel-board.tsx`), а серый для «неактивно»
> где-то `text-slate-500`, где-то `text-slate-600`. Канонично: **`bg-slate-100 text-slate-500`**.
> См. §7.

## 2. Типографика

Шрифт — системный стек из `globals.css` (`system-ui, -apple-system, "Segoe UI", Roboto,
Inter, Arial`). Никаких веб-шрифтов не подключаем — это осознанно (скорость, единый вид).

| Роль | Класс | Размер / вес |
|---|---|---|
| Заголовок страницы (h1) | `text-xl font-bold` | 20px / 700 |
| Заголовок секции / карточки | `text-sm font-semibold` … `text-base font-bold` | 14–16px / 600–700 |
| Крупное число KPI | `text-lg font-bold` | 18px / 700 |
| Основной текст | `text-sm` | 14px / 400–500 |
| Подпись KPI / мета | `text-[11px] text-muted` | 11px |
| **Метка-заголовок** (период, шапка таблицы) | `text-[11px] font-semibold uppercase tracking-wide text-slate-400` | 11px, UPPERCASE |
| Мелкий бейдж | `text-[10px]` … `text-[11px]` | 10–11px |

**Правило бейджа:** один размер для всех чип-бейджей — **`text-[11px]`**. Не смешивать
`text-[10px]` / `text-[11px]` / `text-xs` для одной роли (сейчас смешано — §7).

UPPERCASE с `tracking-wide` — только для коротких меток (период, шапки колонок таблицы),
не для текста длиннее 3-4 слов.

## 3. Сетка, отступы, форма

- **Контейнер экрана:** `mx-auto max-w-[1220px] p-6 space-y-4` (как РОП). Вертикальный ритм
  между секциями — `space-y-4` (16px).
- **Шаг отступов** — кратно 4px (Tailwind scale). Не вводить `p-[14px]`-произвол.
- **Padding карточки** — **`p-4`** (16px) канонично. Плотная карточка в канбане — `p-3.5`
  допустима как осознанно более компактная. Не плодить третий вариант.
- **Радиусы:** карточка/секция — `rounded-2xl` (16px); вложенный блок/кнопка — `rounded-xl`
  (12px); бейдж/чип — `rounded-full`. Значения 12/16 заданы в конфиге.
- **Тени:** только две — `shadow-card` (покой), `shadow-pop` (hover/drawer/поповер). Своих
  `box-shadow` не писать.
- **Разделители:** `divide-slate-100` внутри сеток (как KPI-полоса), `border-slate-100`
  для линий. Тонкий скроллбар — класс `thin-scroll` (определён в `globals.css`).

## 4. Деньги, числа, даты

- **Валюта всего продукта — BYN.** Форматировать через `formatByn()` из
  [src/lib/format.ts](src/lib/format.ts) → `«280 000 BYN»` (разрядность `ru-RU`, пробел-разделитель).
- **`formatMoney()` отдаёт `₽` — это рудимент. В новых экранах не использовать**, пока
  валюта продукта — BYN. (Кандидат на унификацию — см. §7.)
- Числа без валюты — `formatNumber()`. Проценты — целое + `%` (`74%`), прогресс-бар рисует ту же величину.
- Знак динамики: рост — `emerald`, падение — `red`, со стрелкой ▲/▼; ноль — `muted`.

### 4.1 Иконки каналов связи (бренд-цвета)

Каналы коммуникации (звонок/мессенджеры/почта) узнаются **по бренд-цвету**, а не по форме.
Источник истины — [src/components/channels.tsx](src/components/channels.tsx). Цвета фиксированы
(это бренды, не наши токены) и **одинаковы в обеих темах** (в тёмной — те же hex, при
необходимости `brightness` чуть выше):

| Канал | Цвет | Иконка (lucide / react-icons) |
|---|---|---|
| Позвонить / телефон | `#22C55E` | `Phone` (трубка) |
| WhatsApp | `#25D366` | `FaWhatsapp` |
| Viber | `#7360F2` | `FaViber` |
| Telegram | `#229ED9` | `FaTelegramPlane` (самолётик) |
| Email | `#3B82F6` | `Mail` (конверт) |
| ЭДО / 1С, Ссылка на подпись | `muted` (нейтраль) | `FileText` / `Link` |

Правила:
- **Кнопка-действие канала** (позвонить/написать у контакта): квадрат `28×28 rounded-[7px]`,
  заливка бренд-цветом, иконка белая. Звонок — `#22C55E`.
- **Канальная панель отправки** (Email/WhatsApp/Telegram/ЭДО/Ссылка): чип `.btn`/secondary с
  бренд-цветной иконкой слева + текст; фон чипа нейтральный (`surface`), не заливать брендом.
- **НЕ использовать цветные эмодзи** (`🟢`/`✈️`) как иконки каналов — они непредсказуемо
  рендерятся и выбиваются из палитры. Только моно-глиф/иконка, окрашенная бренд-цветом.
- В HTML-макетах (без react-icons) допустимы глифы `●`/`✈`/`✉` с inline `color:<бренд>`.

## 5. Каталог паттернов

Эталонные реализации — в `rop-overview-preview.html` (и соседних `rop-*`). Ниже — правила
формы; точные классы смотри в эталоне.

### 5.1 Вкладки раздела (pill-tabs)
Ряд `flex flex-wrap gap-1.5`. Активная — `bg-brand text-white shadow-card`; неактивная —
`bg-white text-slate-500 shadow-card hover:text-brand-600`. Все `rounded-full px-3 py-1.5`.

### 5.2 KPI-полоса
Секция `rounded-2xl bg-white shadow-card`, внутри `grid` с `divide-x divide-y divide-slate-100`
(на `lg` — `divide-y-0`, 6 колонок). Ячейка `p-4`: крупное число `text-lg font-bold text-ink`
+ подпись `mt-1 text-[11px] text-muted`. Адаптив: 2 → 3 → 6 колонок.

### 5.3 Карточка-метрика / KPI-тайл
`rounded-2xl bg-white p-4 shadow-card`. Заголовок-метка сверху (`text-[11px] uppercase
text-slate-400`), число крупно, под ним — динамика/прогресс-бар.

### 5.4 Прогресс-бар
Дорожка `h-2 w-full rounded-full bg-slate-100 overflow-hidden`; заливка
`h-full rounded-full` + цвет по смыслу (`bg-brand` / `bg-emerald-500` / `bg-amber-500` /
`bg-red-500`) + inline `width:NN%`.

### 5.5 Бейдж / чип статуса
`rounded-full px-2 py-0.5 text-[11px] font-semibold`, пара фон+текст из §1
(`bg-{tone}-50 text-{tone}-600`). Один компонент на проект — см. §7 (нужен `components/ui`).

### 5.6 Канбан-колонка (Sales 2.0 / доска)
Ширина ~284px, `flex-shrink-0`, горизонтальный скролл с `thin-scroll`. Шапка `bg-white
rounded-xl shadow-card`; сверху цветная полоса `height:4px` цвета стадии из `colors.stage`.
Карточка внутри — `bg-white p-3.5`, hover → `shadow-pop`.

### 5.7 Drawer-карточка (раскрытая сделка)
`position:fixed; right:0; top:0; height:100vh`, ширина ~460px (`max-w-[94vw]`),
въезд `translateX(100%)→0`, тень `shadow-pop`. Шапка `p-4`, тело — скролл.

### 5.8 Таблица (Справочники / списки)
Шапка: `bg-white`, ячейки `px-2.5 py-2`, текст `text-[11px] uppercase text-slate-400`,
выравнивание влево. Строка — `border-b border-slate-100`, ячейка `px-2.5 py-2`.
Архивная/неактивная строка — фон `bg-black/5` + текст `muted`.

### 5.9 AI-ассистент / инсайт-блок
Карточка с **левой цветной границей** `border-l-4 border-violet-400` (или `border-brand-100`),
иконка `✦`, фон белый или `bg-violet-50`. Чип-действия — `rounded-full px-2 py-0.5
text-[11px] font-semibold`. Используется во всех кокпитах (РОП/Маркетинг/Контролёр).

### 5.10 Список «Требуют внимания» (alert-стек)
`space-y-2.5`; запись — `rounded-r-lg border-l-2 pl-3` с цветом границы по серьёзности
(red/amber/violet). Inline-бейдж справа — как §5.5.

## 6. Чек-лист нового экрана

1. Контейнер `mx-auto max-w-[1220px] p-6 space-y-4`, фон `bg-canvas text-ink`.
2. Цвета — только токены/семантика из §1. Ни одного нового hex в JSX.
3. Деньги — `formatByn`; числа — `formatNumber`. Не `₽`.
4. Карточки — `rounded-2xl bg-white p-4 shadow-card`. Тени — только `card`/`pop`.
5. Бейджи — `text-[11px]`, пара `bg-{tone}-50 text-{tone}-600`.
6. Метки-заголовки — `text-[11px] uppercase tracking-wide text-slate-400`.
7. Повторяющийся блок есть в §5? — повторить паттерн, не изобретать.
8. Понадобился цвет/паттерн, которого нет? — добавь токен в конфиг и допиши сюда, потом используй.

## 7. Технический долг (порядок порта)

Стиль уже единый — долг в *способе записи*. Чинить по убыванию пользы:

1. **`components/ui/` с примитивами** (`Button`, `Card`, `Badge`/`Pill`, `Table`). Сейчас
   70+ компонентов без общих примитивов → каждый рисует свои `div`. 🔴
2. **Свести дубли тонов** приоритетов/статусов в один типизированный map
   (`priority-badge.tsx` + `deal-actions.tsx` + `funnel-board.tsx` → одно место). 🟠
3. **Убрать hardcoded hex:** цвета каналов связи (`channels.tsx`, `deal-messages.tsx`,
   `leads-workspace.tsx` — там email вообще другого цвета `#7A828F`) и скроллбар `#d8dce3`
   → токены конфига. 🟠
4. **Унифицировать `formatMoney` (`₽`)** под BYN или явно развести валюты. 🟠
5. **Выровнять размеры:** бейджи к `text-[11px]`, padding карточек к `p-4`,
   серый «неактивно» к `text-slate-500`. 🟡
6. **Мигрировать HTML-макеты** Sales/Маркетинг/Контролёр со встроенного `:root`-CSS на те же
   токены (визуально они уже совпадают; расходится только синтаксис). 🟡
