# DESIGN-SOURCES.md — где смотреть и подбирать дизайн

Куда ходить за дизайн-решениями для проекта: вдохновение, готовые компоненты, эталоны.
Под наш стек — **Next.js + Tailwind** — и приоритеты платформы (см. [../PLATFORM.md](../PLATFORM.md)):
деньги → безопасность → функциональность → эстетика.

> Порядок работы: **1)** сначала смотри своё ([DESIGN.md](DESIGN.md) + образцы `*-preview.html`) →
> **2)** если нет решения — иди в галереи за идеей → **3)** бери готовый код из библиотек под Tailwind →
> **4)** адаптируй под наши токены, не копируй вслепую.

## 4. Как подбирать под наши приоритеты (правило отбора)

Любой найденный компонент/экран прогоняй через иерархию платформы:

1. **Деньги** — помогает ли видеть/защищать деньги собственника? (маржа на видном месте, действие к закрытию).
2. **Безопасность** — опасные действия отделены? есть подтверждение/порог?
3. **Функциональность** — все состояния (пусто/ошибка/загрузка/нет прав)? мобайл без обрезки?
4. **Эстетика** — красиво, но не в ущерб 1–3. Не тащить эффектное ради эффектного.

**Не копировать вслепую:** взял компонент → перекрасил под наши токены (`DESIGN.md`) →
проверил на телефоне (без горизонтальной обрезки) → только потом в проект.
