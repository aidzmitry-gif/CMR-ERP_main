Закупки (ZAK) — превью экранов процесса

Статичные снимки экранов модуля закупок (демо-данные, BYN; китайские инвойсы — CNY/$). Сквозной процесс: запрос цены от продавца → уточнение у поставщика → закупка под сделку/пополнение → сбор машины (Китай → Минск) → приёмка и себестоимость → в прайс. На каждом экране справа — панель переписки с поставщиками (WeChat/email/1688), которую ведёт ИИ. Клик по карточке открывает экран; внутри сверху — вкладки.

1 · Обзор / Cockpit эталон
KPI закупок, машины в пути (вехи Китай→Минск), запросы цены без ответа, проверка контрагентов, ИИ-помощник. Справа — панель чатов с поставщиками.
2 · Запросы цены sales ↔ закупки
Продавец просит цену на товар, которого нет в наличии → закупщик уточняет у поставщика → отдаёт цену + срок доставки обратно продавцу.
3 · Воронка закупок
Канбан 9 стадий: Потребность → Поиск → Переговоры → Анализ → Согласование → PO → Производство → Приёмка/QC → Готово. Под сделки + пополнение склада.
4 · Планирование машины логистика
График сбора машины с вехами: выкуп · производство · склад Китай · проверка · отправка · таможня Минск · склад Минск. Заявки собираются в машины заранее.
5 · AI-переписка с поставщиками центр — ИИ
WeChat / email: ИИ переводит, отвечает по шаблону, ведёт переговоры по цене, делает аналитику бесед и готовит документы для закупки/импорта.
6 · Мониторинг цен + контрагенты
Контроль цен на 1688 / Taobao / Alibaba по постоянно закупаемым товарам, алерты на рост, поиск аналогов; проверка надёжности китайских контрагентов.
7 · Себестоимость / Landed Cost база для прайса
Предварительная (для расчёта цены продажи) и итоговая (на приёмке) себестоимость: инвойс + фрахт + таможня + сертификация + логистика, распределённые на номенклатуру → landed cost единицы.

Превью-снимки для просмотра процесса; кнопки и формы внутри не активны, работает навигация по вкладкам/карточкам и панель чатов (наведение).
