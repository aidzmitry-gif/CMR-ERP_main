Двухшаговое закрытие в отказ

Менеджер не может самостоятельно закрыть сделку в «Отказ» — нужно согласование РОПа

1Менеджер

Перетаскивает карточку в колонку «Условный отказ» (cond_lost).

Появляется диалог: «Отправить на согласование РОПа?»

→

2Система

Создаёт запрос approvals.request(route="РОП").

Сделка висит в cond_lost (prob 5%, не считается закрытой).

→

3aРОП согласовал

Стадия → «Закрыто: Отказ» (lost).

Обязателен выбор lost_reason_code из 9 причин.

Emit: sales.deal.lost

→

3bРОП отклонил

Сделка возвращается на предыдущую стадию.

Продавец продолжает работу.

    id             SERIAL PRIMARY KEY,
    owner_id       INTEGER NOT NULL,       -- hr.employee (мягкая ссылка)
    metric         VARCHAR(32) NOT NULL,
    period_type    VARCHAR(8) NOT NULL,    -- day/week/month/quarter/year
    period_key     VARCHAR(10) NOT NULL,   -- 2026-06-12 / 2026-W24 / 2026-06 / 2026-Q2 / 2026

    status         VARCHAR(16) DEFAULT 'draft',
    approved_by    VARCHAR(128),
    approved_at    TIMESTAMP,
    UNIQUE (owner_id, metric, period_type, period_key)  -- uq_plan_target
  )
