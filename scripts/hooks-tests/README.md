# Регрессионные тесты хуков

Страховка для инфраструктуры Claude Code: сторож команд, реестры тронутых файлов, оркестратор
воркеров. Написаны 25.07.2026 по итогам ревизии под Claude Code 2.1.219 — в них зафиксированы
**реальные** дефекты, которые тогда нашли, чтобы они не вернулись молча.

## Когда запускать

После любой правки `claude_*_hook.py`, `spawn_workers.py`, `tg_sessions.py` или
`.claude/settings.json`:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\hooks-tests\run-all.ps1
```

2–4 минуты (каждый набор поднимает хуки отдельными процессами). Поэтому НЕ входит в
`scripts\gate-py.ps1` и не собирается `pytest` — тот берёт только `tests/`.

## Что проверяет каждый набор

| Файл | Что защищает |
|---|---|
| `test_guard.py` | 51 сценарий сторожа. Половина — что он НЕ мешает рутине (`grep .env \| head`, `ruff check --diff`), половина — что ловит настоящее (`cat .env`, `rm -rf /`, `curl \| sh`, PowerShell-формы). Отдельно помечены `[RG]` — обходы, найденные адверсариальным аудитом: heredoc с повторным терминатором, подстановка `$()` внутри `-m`, выгрузка секрета через конвейер. |
| `test_hooks_smoke.py` | Все девять хуков отвечают без падений на всех событиях, включая `source=fork` и `DirectoryAdded`, с кириллицей и эмодзи в данных и БЕЗ `PYTHONUTF8` в окружении. |
| `test_parent_hooks.py` | Хуки ведут себя одинаково, из какого бы каталога ни стартовала сессия, и не создают лишний `coordination/` у родителя. |
| `test_ledger_owner.py` | «Файл занят другой сессией»: свой и свой-сабагентский реестр пропускаются, чужой блокируется — в т.ч. чужая сессия с похожим началом id. |
| `test_subagent_stop.py` | Уборка реестров: сабагент чистит свой на `SubagentStop`, родитель — свой и заведомо протухшие, но не трогает файл живого сабагента. |
| `test_loop_contract.py` | Модель, усилие и денежный лимит воркера читаются из его ТЗ, включая канонический вид с комментарием в строке (`model: sonnet   # тир: ...`) — на этом формате разбор молча ломался. |

## Если набор упал

Красный `test_guard.py` — самое важное: либо сторож начал пропускать опасное, либо снова мешает
рутине. Вывод показывает конкретный сценарий и ожидавшийся код возврата (`2` — блок, `0` — можно).

Тесты ничего не пишут в репозиторий: все макеты создаются во временных каталогах и удаляются.
