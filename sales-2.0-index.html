Сделки 2.0 — все макеты

Кликни по карточке, чтобы открыть экран. Это самодостаточные HTML-демо (работают офлайн). Бэкенд по ним ещё не написан.
главная
🗂️
Доска сделок
Sticky-скорборд План/Факт + индикатор темпа, несколько воронок (новые / постоянные / тендеры), 9 стадий с ценой ДО встречи, рейка чатов.
🧮
Конструктор плана продавца
План собирается из 3 источников (товар в пути / постоянные / новые) + калькулятор-декомпозиция по действиям и обратный счёт дефицита.
🚚
Сквозной статус машины
Весь путь поставщик→склад→клиент. Источник истины — логистика. Внутренний вид vs кабинет клиента (себестоимость скрыта).
♻️
Постоянные клиенты / перезаказ
Статусы цикла (в цикле / пора связаться / уходит), KPI удержания, перезаказ и допродажа. Что происходит после продажи.
📈
Валовая прибыль по месяцам
Загрузка машин/товаров помесячно, плановая вал. прибыль и маржа (продажа − landed cost). Видно недозагруженные месяцы.
 2 клика
📇
Карточка сделки (полный экран)
Открывается двойным кликом по сделке. AI-ассистент, звонки с транскрибацией, статус машины, оплата, доставка, контакты с кнопками звонка, отправка договора/счёта, хронология. Блоки можно убирать.
 телефония
📞
Окно входящего звонка (screen-pop)
Всплывает при звонке: узнан клиент + сделка + AI-подсказка, либо новый номер → лид. Состояния: разговор, итог звонка, транскрибация. Резерв под счёт.
 подбор
🛒
Каталог-подбор в счёт
Просторный каталог: поиск/группы, остатки по складам и «в пути», прошлая→текущая цена. Подобранные позиции справа уходят в счёт (итог + НДС + деление дефицита приход/закупка); ℹ → карточка товара в «Справочниках» (МДМ).
 реестр
🗂️
Реестр документов (все)
Единый реестр всех документов CRM: счета/договоры/КП/акты/заказ-наряды/ТТН. Видимость по роли (менеджер→свои, РОП→отдел, директор→все), фильтры и группировка, врезка в отдел.
 согласование
📄
Документооборот сделки
Чистый блок «Документы» из карточки + принципы: не удаляем (только пометка), правка → новая версия, подписанный/оплаченный заморожен, отправка помеченного запрещена.
 вне CRM
🗄️
Архив документов (удаление)
Куда попадают документы, помеченные на удаление в сделках. Безвозвратное удаление — только здесь, по доступу (роль архивариуса). Версии, восстановление, журнал аудита, ИИ-проверка причин.
🗂️
Карточка-слайдовер (1 клик)
Быстрый предпросмотр справа по одиночному клику на доске (drawer).
🔀
Доска: До / После
Сравнение старого вида доски и нового со скорбордом и темпом.
📋
Обзор изменений SALES 2.0
Сводка тикетов и решений по блоку Сделок.
