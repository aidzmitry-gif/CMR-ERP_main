# План: себестоимость и цена из 1С — ночной автономный прогон (no-rework)

> Для автономного `/loop` (инженерные циклы + Workflow/сабагенты). Решение оператора
> (см. память `cost-price-from-1c-decision`): **себестоимость И цена продавца — из 1С**
> (учётная себес + справочник цен). Приоритет №1 — деньги: ошибка в себес/цене = потери,
> поэтому контракт и маржа — Opus+high, гейты жёсткие.

## Принцип «не переделывать»
Строим **ШОВ** — фасад ядра `PriceCostGateway`, который отдаёт по SKU `{цена, себес,
источник, дата}`. Все потребители (маржа сделки, дефолт цены в КП, дефолты конструктора
плана) читают ТОЛЬКО фасад. Когда 1С оживёт — реальный источник за фасадом подменяется,
**потребители не трогаются**. Ночью источник = «нет данных / dev-фикстура»; в офисе →
реальная 1С. Так ночная работа не выбрасывается.

## Архитектура данных (КАК цены/себес доходят до продаж) — важно
Цены/себестоимость — СПРАВОЧНЫЕ данные с историей → **золотая запись в справочнике/MDM**,
НЕ параллельная правда в продажах. Поток:
`1С → integrations (коннектор, чтение) → справочник/MDM (цена+себес как golden-атрибуты SKU,
провенанс source=1С, SCD2-история, сверка с landed) → модули через фасад ядра`.
- **Фасад `PriceCostGateway` = reference-backed:** за ним стоит золотая запись справочника,
  которую наполняют полосы **Справочники/MDM + integrations** (офис + их сессии, НЕ эта полоса).
  Продажи только ПОТРЕБЛЯЮТ через фасад — своей «правды» не заводят.
- **Остатки — НЕ в этот план и НЕ в справочник:** транзакционные, у них свой `StockGateway`
  (1С=истина, живое чтение, `core.services.stock`). Здесь их не трогаем.
- **Правило:** модули в 1С напрямую не ходят — только через ядро/фасад.
Ночью строим только ПОТРЕБИТЕЛЯ под этот контракт; наполнение справочника из 1С — офис + их полосы.

## 🔴 Границы — НЕ трогать ночью (это офис / чужая полоса)
- **Модуль `modules/integrations`** — территория сессии-синхронизатора. Коннектор к 1С
  НЕ строим. Только КОНТРАКТ в ядре (`core/services/`), impl — их.
- **1С write заморожен** — контракт строго на чтение (см. `onec-write-frozen`).
- **Креды/URL 1С, включение OData** (`onec_base_url`, `config/settings.py`) — офис,
  оператор/админ. Настройки не правим.
- **Выбор конкретных регистров 1С** (тип цены: оптовая/…, регистр себестоимости) —
  требует реальной 1С. Ночью НЕ выбираем, оставляем в контракте параметром.
- **Миграций быть НЕ должно:** цену/себес читаем через фасад, локально НЕ храним →
  новых таблиц нет. Если цикл тянет за миграцию — СТОП, это сигнал ошибки дизайна.
- **Хотспоты** (`core/services/__init__.py`) — точечно, одно поле, свой коммит.
- **Не пушить** — оператор пушит сам. **Не трогать** `.claude/settings.json`,
  `catalog-picker-modal.tsx`, `logistics-scorecard.tsx`, `launch.json`, `coordination/*`,
  `frontend/src/lib/api.ts` (импорт — ок, правки — в split-файлы).

## Циклы (каждый = свой коммит + КООРД; гейты в конце каждого)

### Цикл 1 — Контракт-шов `PriceCostGateway` (ядро) · Opus+high
- Новый `core/services/price_cost.py`: `Protocol` + dataclass `ItemPriceCost`
  `{cost_byn: float|None, price_byn: float|None, currency: str, price_type: str|None,
  as_of: date|None, source: 'onec'|'landed'|'demo'|None}`. Метод
  `async get_item_price_cost(session, sku_codes: list[str]) -> dict[str, ItemPriceCost]`.
  Форма ГИБКАЯ под 1С (тип цены + дата актуальности), но не привязана к её схеме.
- Поле в `Services` (`core/services/__init__.py`): `price_cost: PriceCostGateway | None = None`
  (по образцу `landed_cost`). None → честная деградация (нет данных, НЕ ноль).
- **DoD:** контракт + unit-тест на форму/деградацию; `ruff check .`; `pytest` зелёный;
  `alembic heads` == 1 (миграций не добавляли).

### Цикл 2 — Честное пустое состояние + опц. dev-фикстура за флагом · Sonnet+medium (гейт по деньгам)
- Пока 1С нет: фасад `price_cost` = None → потребители показывают «цена/себес из 1С —
  подключается» (НЕ фейковые деньги; PLATFORM #1 честность).
- ОПЦ. dev-фикстура `DemoPriceCostSource` (детерминированная, из `sku`/seed), `source='demo'`,
  активна ТОЛЬКО при `AIOS_ENVIRONMENT=dev` И явном флаге `AIOS_DEMO_PRICE_COST=1`. В UI
  метка «демо, не 1С». НЕ в `integrations`, НЕ в проде. Регистрируется в `create_app` при dev+флаг.
- **DoD:** тест — без флага фасад None (деградация), с флагом (dev) отдаёт данные+source='demo';
  в prod фикстура НЕ активна. `ruff`/`pytest`.

### Цикл 3 — Потребление в марже продаж · Opus+high (деньги)
- `modules/sales` `_deal_margin`: приоритет источников себес/цены —
  `price_cost (onec)` → сверка/фолбэк `landed_cost` → нет. Цена клиенту: если у позиции нет
  котировки КП — дефолт из `price_cost.price_byn` (прайс 1С) с пометкой источника; КП всегда
  перекрывает. `MarginLine` несёт `cost_source`/`price_source`.
- Не ломать текущую деградацию (facade None → как сейчас).
- **DoD:** тесты маржи: с фасадом (onec/demo), только landed, ничего (деградация), КП
  перекрывает прайс; `ruff`/`pytest`.

### Цикл 4 — Провенанс в UI · Sonnet+medium
- Метки «источник: 1С» (и «демо» для фикстуры) на себестоимости/цене/марже в карточке
  сделки, drawer, КП. Паттерн — как `mdm-1c-data-provenance-ui`. Split-API, не `api.ts`.
- **DoD:** `tsc`0 / `lint` (≤ порога) / `vitest`; смоук на :3210 (карточка сделки — метки видны).

### Цикл 5 — Дефолты конструктора плана из фасада · Sonnet+medium
- `plan-sources`/конструктор: `avg_check`/`margin_pct` в блоке «Новые» — дефолтить из
  `price_cost` (средняя цена−себес по 1С), с пометкой источника; продавец может переопределить.
- **DoD:** тест дефолтов; `tsc`/`lint`/`vitest`; смоук.

### Цикл 6 — Адверсариальная верификация (Workflow, 3 opus-линзы) + фиксы
- Линза деньги: приоритет источников себес/цена, КП-перекрытие, деградация не ноль.
- Линза честность: провенанс не врёт (demo≠1С), пустое состояние честное, PLATFORM #1–2.
- Линза границы/дизайн: нет 1С → корректно; demo не в проде; токены C/D, обе темы, no-drop.
- Починить подтверждённые. Повторить гейты.

### Цикл 7 (если осталось время) — хвост no-rework
- SSR-вспышка owner-override на доске (мелкий хвост плана продаж) — тоже не переделывать.

## Guardrails автономного прогона
- **Тиринг:** Opus+high на контракте/марже/судье (циклы 1,3,6); Sonnet+medium на UI/скаффолде
  (2,4,5). Не наследовать дорогую модель вслепую (см. `MODEL-TIERING.md`).
- **Гейты каждый цикл** (блокируют коммит): бэк `ruff check .` + `pytest` + `alembic heads`==1;
  фронт `tsc --noEmit` 0 + `next lint` (warn ≤ 47) + `vitest run`. Живой смоук на :3210 для UI-циклов.
- **Коммит по циклу** своими файлами по имени (`git add <files>`, НЕ `add .`), проверка
  `git diff --cached --name-only`. **Пуш — НЕ делать** (оператор сам). Новый коммит, не amend.
- **Стоп-условия:** цикл упёрся в неизвестную форму данных 1С → СТОП, пометить `BLOCKED-office`,
  не гадать. Понадобилась миграция → СТОП (значит поехали не туда). Нужна правка `integrations`/
  `settings.py`/1С-write → СТОП (чужая территория/заморозка).
- Между волнами — компакт на границе цикла (см. `auto-compact-token-discipline`).

## Оставляем в ОФИС (чек-лист — оператор + сессия-синхронизатор)
1. **Оператор/админ:** поднять 1С-сервер, включить OData (документ готов, `onec-odata-setup`),
   дать бэкенду `onec_base_url` + креды.
2. **Сессия-синхронизатор (модуль `integrations`):** реализовать `PriceCostGateway` из Цикла 1 —
   pull цен (регистр «Цены номенклатуры», выбранный тип цены) и себестоимости из 1С; write НЕ включать.
3. **Оператор:** выбрать тип цены (оптовая?) и регистр себестоимости на реальной 1С.
4. **Оператор+я:** сверка 1С-себес vs landed на реальных данных; решить, что показываем/как метим.
5. Отключить dev-фикстуру из активного пути, когда 1С живая (флаг `AIOS_DEMO_PRICE_COST` в 0).

## Как запустить ночью
- Автономный `/loop` (само-пейсинг) с задачей: «выполняй `1c-cost-price-plan.md` цикл за циклом,
  соблюдая Guardrails; каждый цикл — коммит без пуша + КООРД; на стоп-условии — BLOCKED-office и
  переходи к следующему выполнимому циклу».
- Внутри цикла — Workflow/сабагенты по тирингу выше (реализатор + адверсариальная верификация).
- Лучше в отдельном worktree-бранче (`git worktree add ../_wt_1c -b sales-1c-cost-price`), чтобы
  HEAD не дрейфовал ночью; пуш утром вручную после вашей проверки.
