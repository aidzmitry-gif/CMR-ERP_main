# Приёмка первого реального месяца

Статус: **не выполнена — контрольные данные и подтверждения бухгалтера не приложены**.

Этот документ заполняется отдельно для каждого юрлица и каждого проверяемого месяца. Он связывает реальные первичные документы, ожидаемые проводки и результат ERP. Синтетические тесты не заменяют его заполнение.

## Паспорт проверки

| Поле | Значение |
| --- | --- |
| Юрлицо / УНП / ID организации ERP | Не заполнено |
| Месяц / дата переноса остатков | Не заполнено |
| Версия ERP / версии модулей / применённая миграция | Не заполнено |
| Версия учётной политики / дата утверждения | Не заполнено |
| Проверенные нормативные источники и редакции | Не заполнено |
| Ответственный бухгалтер | Не заполнено |
| База проверки / идентификатор резервной копии | Не заполнено |
| Источник фактических данных: выгрузка 1С и период | Не заполнено |

Проверку выполнять на отдельной базе. Исходные файлы хранить с датой получения и SHA-256; в публичный репозиторий не включать реальные выписки, персональные данные и первичные документы.

## Комплект до начала проведения

- Утверждённая политика юрлица: методы оценки запасов, распределения затрат, амортизации, валютных операций и закрытия; применимые налоги и ставки.
- Соответствие счетов 1С рабочим счетам ERP с аналитикой. Неизвестные соответствия оставлять неразрешёнными; не подменять основной компанией или общим контрагентом.
- ОСВ на дату переноса: счета, субсчета, контрагенты, договоры, документы расчётов, склады, номенклатура, партии, валютные суммы и количество там, где применимо.
- Полные банковские выписки, кассовые документы, поступления, продажи, возвраты и авансы проверяемого месяца.
- Документы ВЭД, НДС/ЭСЧФ и дополнительные расходы; при наличии — производство, НЗП, ремонты, основные средства и проверенные внешние начисления зарплаты.
- Эталонные проводки и контрольные отчёты 1С за тот же месяц. Исторические операции, остающиеся в архиве 1С, не загружать повторно как новые операции ERP.

Если операция не автоматизирована, бухгалтерская справка допустима только с явным основанием и согласованными проводками. Это не означает готовности автоматизации такого типа операции.

## Реестр контрольных операций

Для каждой операции заполнить отдельную запись по образцу:

| Поле | Значение |
| --- | --- |
| ID проверки / тип операции | Не заполнено |
| Исходный документ / версия / SHA-256 | Не заполнено |
| Дата документа / хозяйственной операции / отражения | Не заполнено |
| Ожидаемые Дт и Кт / аналитика / сумма BYN | Не заполнено |
| Валюта / исходная сумма / курс, дата, масштаб и источник | Не применимо или не заполнено |
| Количество / склад / партия / принадлежность имущества | Не применимо или не заполнено |
| Правило расчёта / версия политики | Не заполнено |
| ERP: ID пакета / проводки / квитанции | Не заполнено |
| Фактический результат / расхождение | Не проверено |
| Объяснение / исправляющий документ / повторная проверка | Не заполнено |
| Решение бухгалтера / дата / основание | Не принято |

Минимальный набор выбирается из реальной деятельности: закупка и частичная продажа, частичная оплата, аванс и зачёт, возврат/возврат денег, поздние расходы, валютная операция, исправление закрытого периода. Для применимых направлений добавить НЗП, выпуск, гарантийный ремонт с имуществом клиента, амортизацию и зарплату. Неприменимость фиксировать с причиной.

## Последовательность месячной проверки

1. **Остатки.** Сверить исходную ОСВ с импортом по счетам и аналитике; повтор импорта не создаёт дублей. Сохранить протокол и идентификаторы пакетов.
2. **Полнота.** Разобрать очереди непроведённых документов, первичных источников и банковских строк. Список необработанного за месяц должен быть пуст или блокировать закрытие; исключение из проверки не является устранением ошибки.
3. **Деньги и расчёты.** Сверить счета и суммы с выписками, долги и авансы — с документами. В банковском пилоте импортируется входящий BYN; другие операции отдельно учитывать в реестре покрытия.
4. **Склад и стоимость.** Сверить собственные количества и стоимость; отделить имущество клиента. Проверить списание резерва при отгрузке, снятие остатка и распределение поздних расходов. Предварительную стоимость не принимать за окончательную.
5. **Регистры.** Проверить применимые НДС/ЭСЧФ, ВЭД, зарплату, ОС и производство. Связать каждое основание с записью регистра и проводкой.
6. **Закрытие.** Выполнить шаги утверждённой политики, проверить зависимости расчётов, сохранить квитанцию закрытия. При изменении исходных данных повторить зависимые расчёты и сверки.
7. **Отчёты.** Сопоставить ОСВ, ДДС, прибыль и убытки, баланс за одинаковые даты. Все месяцы диапазона должны быть закрыты; незавершённые проверки сохраняют предварительный статус. Проверить капитал по учтённым остаткам, не вычислять его для сокрытия разницы баланса.
8. **Восстановление.** Восстановить копию проверенной версии в отдельную базу. Сравнить данные и отчёты, проверить неизменяемость истории и отсутствие повторных движений.

| Применимые налоговые и иные регистры | Не проверено |
| Все расхождения объяснены и ошибки ERP исправлены | Не подтверждено |
| Квитанция закрытия / отчёты / версии данных | Не получено |
| Восстановление актуальной базы | Не проверено |
| Решение бухгалтера по этому месяцу | Не принято |

Первый принятый месяц не даёт полного разрешения отказаться от 1С. Общий план требует двух последовательных принятых закрытий, проверки применимого квартального цикла и пробной годовой отчётности. Решение фиксирует ответственный бухгалтер; отправка внешней отчётности выполняется уполномоченным пользователем после проверки.
