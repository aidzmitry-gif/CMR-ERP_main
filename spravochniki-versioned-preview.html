Как берётся курс на дату (structured)

AI и документы получают точное значение структурным запросом поверх semantic-слоя — не через эмбеддинги. Полуоткрытый интервал гарантирует ровно одну версию на любую дату.

SELECT rate
FROM   public.currency_rates
WHERE  base = 'USD' AND quote = 'BYN'
  AND  valid_from <= :doc_date            -- действует с
  AND  (valid_to IS NULL OR :doc_date < valid_to)  -- по (полуоткрыто)
LIMIT  1;
-- :doc_date = 2026-05-15  →  rate = 3.25
Как это устроено
  • 🕘Текущая версия = «по» пусто (end_date IS NULL); прошлые версии не перезаписываются, а закрываются датой начала следующей.
  • ◷Интервал действия полуоткрытый [действует с, по) — дата «по» в период уже не входит, поэтому версии стыкуются без перекрытий и зазоров.
  • 🗃SCD Type 2 ведётся вручную (триггер/сервис-слой), т.к. стек — PostgreSQL 16; нативные temporal-таблицы (FOR PORTION OF) появляются в PG18/19.
