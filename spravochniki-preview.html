Справочники — единый реестр

Витрина поверх данных, которыми владеют ядро и модули. Дублей нет: данные остаются у владельца.

Как это устроено: 📇 это реестр-витрина, а не второе хранилище 🔒 у каждого справочника есть владелец 🗃 архив вместо удаления 🕘 у части справочников — история по датам 🤖 точный доступ для AI
Значки: ★ мастер-данные (golden record) 🕘 версионный (история по датам) 🌳 иерархия (дерево) 🤖 в каталоге для AI

каталог 
{
  "key": "counterparties",
  "title": "Контрагенты",
  "endpoint": "/refs/counterparties",
  "owner": "public",
  "columns": [
    { "code":  "стабильный код ссылки" },
    { "title": "наименование" },
    { "unp":   "налоговый № (natural key)" },
    { "is_active": "архивные не выбираются" }
  ]
}

AI берёт точные значения отсюда структурным запросом — не угадывает и не использует эмбеддинги для точных полей.
